# 📚 NotificAtraso

Sistema web para registro e gerenciamento de atrasos de alunos.

---

## 🚀 Funcionalidades

* 🔐 Login de funcionários
* 👨‍🎓 Registro de atrasos por matrícula
* 👨‍🏫 Seleção de professor com autocomplete
* ✏️ Edição de atrasos
* ❌ Exclusão de atrasos com confirmação
* 📋 Listagem de atrasos por aluno
* 🛡️ Proteção de páginas com sessão

---

## 📧 Envio de E-mail

O sistema possui envio automático de e-mail para responsáveis utilizando PHPMailer.

⚠ **Importante:**
Atualmente, essa funcionalidade pode estar **temporariamente desativada** para testes, evitando o envio real de e-mails.

👉 Para ativar novamente:

* Consulte o arquivo de instruções específico no projeto (configuração de SMTP e senha de app).

---

## 💻 Como Executar

1. Instale o XAMPP
2. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/notificatraso.git
```

3. Coloque na pasta:

```
C:\xampp\htdocs\
```

4. Importe o banco de dados no phpMyAdmin

5. Inicie:

* Apache
* MySQL

6. Acesse no navegador:

```
http://localhost/NotificAtraso
```
